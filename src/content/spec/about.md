# 关于我

这里是 mio 的小窝。

我平时会写一点代码，折腾博客，学 Java、Spring、前端，也会把看过的书、踩过的坑和一时没想明白的东西先记下来。很多时候学习并不算特别系统：看懂了不等于会用，写过了也不等于记住。所以我想把这些零散的东西慢慢整理起来，变成以后还能看得懂、用得上的知识。

我不是一个很自律的人，经常会开新坑，过一阵子又跑去折腾别的；有些文章写得不够好，有些计划也确实没能坚持下来。但至少先把它们留下来，过段时间回头看，也能知道自己走过哪里，还差些什么。

这个博客不太追求把一切都写得很专业，更像是一个公开的学习记录和个人存档。这里会有代码，也会有阅读、番剧和生活里的小事。内容可能不总是完整，但尽量保持真实。

## 这里有什么

- **Posts**：相对完整、愿意反复修改的文章和学习记录。
- **Notes**：还在持续补充、复盘和关联的公开知识单元。
- **番剧**：我的追番清单，记录正在看、看完、想看和搁置的作品。
- **Obsidian**：本地编辑与整理入口，公开内容最终以 Markdown 文件为准。

如果你也在学编程，或者刚好对这里的某篇文章、某个坑有不同的理解，欢迎来聊聊。能帮到别人当然很好；如果只是一起确认“原来这里也会踩坑”，也挺好。

## 联系方式

你可以通过导航栏中的 GitHub、X 或 Bilibili 找到我。评论区使用 GitHub Discussions，欢迎留下友善的交流。
