# 博客写作台

`Ctrl+Alt+N` 打开 QuickAdd，选择“博客草稿”或“公开知识笔记”。输入标题后，会创建带完整属性的 Markdown 笔记，并放到对应目录。

## 写作流程

1. 新建草稿，填写分类、标签和摘要，再写正文。
2. 检查 `published` 和 `updated` 日期；`updated` 不会随每次保存自动改写，需要发布更新时手动修改。
3. 准备发布时将 `draft` 改为 `false`，按博客原来的预览、检查、提交和发布流程继续。新模板不会自动发布。

本库属于公开博客仓库。`draft: true` 只控制网站展示，不能让已提交到公开仓库的文件变成私密文件。

日记、课程原始资料、个人项目和网页摘录放到独立的 `D:\Obsidian\Mio-个人笔记`，通过 Obsidian 的库切换入口打开。

## 插件入口

- `Ctrl+Alt+O`：Omnisearch 搜索笔记。
- `Ctrl+Alt+L`：Linter 手动整理当前笔记的空白；不会自动更新文章日期和属性。
- Excalidraw：在命令面板选择新建绘图；需要发布图像时手动导出 PNG 或 SVG。
- PDF++：打开 PDF 后摘录并链接回原文。
- LaTeX Suite：在数学公式区域使用公式快捷输入。

原来的 Typora-Vue 主题继续保留，当前使用 Minimal；图片上传设置和 Git 设置继续保留。插件安装完成后，等你方便时重启 Obsidian，让文件配置加载；本次没有关闭、重启或切换你正在使用的窗口。

## 写作文件列表

File Explorer++ 已配置为隐藏工程目录和代码文件，保留以下写作内容：

- `src/content`：文章、公开知识、动态、系列和关于页面。
- `templates`：博客和知识笔记模板。
- `docs/Obsidian`：写作台、索引、临时记录和绘图。
- `docs/knowledge-system.md`：公开知识库维护规范。

`Ctrl+Alt+H` 切换文件列表的隐藏状态；再次按下恢复写作视图。也可以在命令面板运行 `File Explorer++: Toggle all hide filters`。设置中的 File Explorer++ 可以调整隐藏规则。

隐藏只影响左侧文件列表，文件仍在原目录，图片嵌入、Git 和博客构建继续使用原路径。搜索沿用独立的“排除文件”设置，切换文件列表不会改变搜索范围。等方便时重启 Obsidian 加载新插件；本次没有更改当前窗口和工作区布局。

## 写作编辑

当前主题为 Minimal 9.1.4，保留原来的浅色模式，使用柔和紫色强调色。原来的 Typora-Vue 主题仍然保留，可在“设置 → 外观”中切回。

- Editing Toolbar 4.1.10：编辑笔记时在顶部显示精简工具栏，包含标题、加粗、斜体、列表、引用、链接和代码。标题按钮可以展开选择级别。
- Outliner 4.10.2：在列表内使用 Tab / Shift+Tab 缩进或退级，Ctrl+Shift+↑ / ↓ 移动一组知识点及其子项目。Ctrl+A 保持普通全选行为。
- Advanced Tables 0.23.2：在 Markdown 表格内用 Tab / Shift+Tab 切换单元格，Enter 进入下一行；表格控制仍可从命令面板打开。

首次使用前，等方便时重启 Obsidian 加载新插件。插件与主题文件已检查；工具栏显示、按键和主题的实际效果需要加载后确认。
